# EDVCODER FINANCE

Maquette frontend (HTML/CSS/JS vanilla + Chart.js via CDN).

## Lancer
Ouvrir `index.html` dans le navigateur (connexion internet requise pour Chart.js et la police).
Connexion fictive : n'importe quel e-mail contenant @ et un mot de passe de 4 caractères ou plus.

## Données
Stockées dans le localStorage (clé `edv_fin_v1`). Pour réinitialiser : vider le localStorage du site.
